## 一、先回答最重要的问题：名字对得上吗？

**能，而且非常好。**

BirdNET 2.4 的标签格式是 `学名_英文名`（例如 `Cettia cetti_Cetti's Warbler`），
学名就明明白白写在标签里，而本项目的 `nameSci` 字段 **11,131 条 100% 覆盖、全唯一、零冲突**。
两边用的是同一套国际学名，所以对表几乎无损。

### 对表结果（BirdNET 2.4 共 6,522 个标签）

| 匹配方式 | 命中数 | 占比 | 说明 |
|---|---:|---:|---|
| 学名精确匹配 | 6,151 | **94.3%** | 主路径：标签自带学名 |
| 英文名精确匹配 | 203 | 3.1% | 学名对不上时的补救 |
| **精确命中合计** | **6,354** | **97.4%** | ✅ 远超 85% 门槛 |
| 只能确定到「属」 | 61 | 0.9% | 诚实降级，不冒充具体种 |
| 完全对不上 | 107 | 1.6% | **全是非鸟** |

**那 107 个"对不上"的到底是什么？** 逐个检查其学名属是否出现在本项目里：
**0 个出现**。也就是说这 107 个全是蛙、蟋蟀、猴、螳螂、蟾蜍之类——
BirdNET 内置的非鸟类别，而本项目只收鸟类。

> **结论：鸟类标签的命中率是 100%**（6,415 个鸟类标签全部对上，其中 6,354 个精确到种、
> 61 个精确到属）。剩下的 1.6% 不该算作"识别不出来"。

### 一个需要注意的细节

6,354 个精确命中里，**只有 5,146 个（81%）能对应到本项目当前可播放的物种**。
差的 19% 是因为 053 的全球种采集还没走到那些鸟（目前 9839 / 11131）。
**这个比例会随采集完成自己涨上去，不需要额外做��。**

## 三、但是：识别准确率要如实说

标签对得上 ≠ 模型认得准。这两件事必须分开看。

我拿项目里的真实音频做了两组抽样（每条音频在项目里归属于哪个种是已知的，可直接核对）：

### A 组：字母序靠前的冷门岛特有种（10 条）

**top-3 命中 2 条（20%）**

- ✗ 杜氏凤头鹦鹉 → 认成东方冠斑犀鸟（39.8%）
- ✗ 古巴钩嘴鸢 → 认成**同属**的钩嘴鸢（57.0%）← 属对了，种没对
- ✗ 哈岛鹃鵙 → 认成北摩鹿加鹃鵙（同科不同属）
- ✓ 鲑色凤头鹦鹉 排第 3
- ✓ 米切氏凤头鹦鹉 **排第 1，置信度 99.77%**

### B 组：按常见度分层抽样（5 条）

**top-3 命中 3 条（60%）**

- ✓ 西棕扇尾莺 `Cettia cetti` **第 1 位，99.84%**
- ✓ 草原鹞 `Circus macrourus` **第 1 位，91.84%**
- ✓ 蓝-fronted Robin `Cinclidium frontale` 第 1 位（但置信度仅 3.59%）
- ✗ 哈岛鹃鵙、朱顶蕉鹃 — 仍是冷门特有种，同 A 组

### 由此得出的判断

**模型在广布常见种上很准（top-1、置信度 90%+），在冷门岛特有种上很弱（常落在 top-5 之外，或只到属级）。**

原因是训练数据分布：BirdNET 靠全球大量 soundscape 训练，
广布种见过成千上万次，太平洋岛屿特有种可能只见过个位数。

**这对功能定位的影响（必须写进设计）：**

1. **不要承诺"这是答案"**。置信度要原样显示，用户自己能看出 3% 和 99% 的区别。
2. **低置信度要显式提示**。建议阈值：<10% 时提示"模型也不确定"。
3. **属级命中要诚实显示**（如"只能确定到属：Accipiter 鹰属"），不要冒充具体种。
4. **这个功能的价值不在"答对题"，而在"给方向 + 展示素材"**——
   对冷门种，它至少能告诉用户"大概是鹰属的一种"，然后展示该属在本项目的素材。

## 四、其他实测发现

| 项 | 结果 |
|---|---|
| 中国网络下载模型 | Zenodo 单流 **12–22 KB/s**（50MB 要 70 分钟且会断）；**16 线程分块并发 ≈ 185 KB/s，313 秒下完** |
| GitHub raw 域名 | **被墙**；`api.github.com` 可用，用它 base64 取文件可绕过 |
| TFLite → ONNX 转换 | **失败**（`tflite2onnx` 不支持图内的 `REDUCE_MIN` 算子）。改用 `ai-edge-litert` 直接跑 TFLite，绕开转换 |
| 中文标签 `labels/zh.txt` | 包里有，但实际**几乎全是英文回退**，中文名对表价值为 0（不过学名匹配已经够用） |
| 模型体积 | TFLite 权重 25MB + meta-model 28MB（浏览器端只需 audio-model 那份） |
